# Code signing policy

Free code signing provided by [SignPath.io](https://about.signpath.io), certificate by [SignPath Foundation](https://signpath.org).

*(Signing via SignPath is pending approval: releases published before approval are unsigned.)*

## What is signed
Only Windows binaries built by GitHub Actions from this public repository (`learnaing-<version>-setup.exe`, `learnaing-<version>-portable.exe`). Nothing built on a personal machine is submitted for signing.

## Team roles
- Committers and reviewers: [ilgrandeg1anfi1-hue](https://github.com/ilgrandeg1anfi1-hue)
- Approvers: [ilgrandeg1anfi1-hue](https://github.com/ilgrandeg1anfi1-hue)

All team members use multi-factor authentication on GitHub and SignPath.

## Privacy
This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. See [PRIVACY.md](PRIVACY.md).
